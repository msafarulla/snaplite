# Logos for the Insert Logo picker

Drop logo image files here (`.png` preferred, transparent background; `.jpg`/`.webp` also work).
Every image in this folder appears automatically in the editor's **More ▾ → Insert Logo…** grid; the
filename (without extension) is shown as its tooltip. After adding or removing files, rebuild the app
(`tools/install.sh`) so the bundled assets update.

Note: company/brand logos are trademarks of their owners. Only add logo files you have the right to use.
This README is ignored by the picker (it lists image files only).
